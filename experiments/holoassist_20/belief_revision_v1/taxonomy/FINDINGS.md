## Denominators and non-overlap

100 requests across 20 videos; 85 qualified requests from 17 videos; 170 qualified field observations (138 known, 32 required unknown); 30 fields excluded for unresolved targets. The 170 observations repeat only 34 capture-time claims. They are not 170 independent events. There are 51 eligible fixed-claim transitions and 17 same-claim consistency checks.

The primary claim-level view collapses same-request aliases: **153 qualified claim/request checks**, 105 with matching values and 48 with a value error or internal inconsistency. These are repeated checks of 34 endpoint claims, not 153 independent events.

Counts partition their own unit only. Do not add state errors, citation errors, consistency violations and transition failures to make a total: those describe different aspects of some of the same responses.

Task qualification is separate: HA05/HA09 have curated D01 blockers (target identity/occurrence); HA10 has a D04 blocker (task/positive-window mismatch). HA06/HA08/HB06 are qualified with unsettled A evidence (D02), not invalid tasks. All of these findings remain single-reviewer judgments.

## Reading the partitions together

The **60/170 state errors** consist of 34 abstentions on provisionally known states, 19 opposite binary values and seven commitments on unsettled evidence. There are no premature commitments before A in the qualified set. These are output descriptions, not proven internal causes.

The 14 same-claim inconsistencies are all unknown-versus-binary certainty disagreements; **zero are opposing yes/no contradictions**. Both fields refer to A at the first chronological step.

For the 138 known fields, citation categories are: E00=58, E01=0, E10=66, E11=14, E12=0. E00 means the requested packet is named; the predicted value can still be wrong.

Among 85 correct known-value observations, 43 have an incorrect citation result: 29 omit required support and 14 cite the wrong capture-time packet. Conversely, 16 opposite-binary answers name the requested packet. This is why citation IDs and answer values need separate partitions.

## Trace-backed boundary examples

- **HB01:** chronological earlier no -> unknown is T13, loss of an initially correct value. Reversed latest no -> no is T15, a persistent prior error; calling it forgotten knowledge would be wrong.
- **HA01:** reversed earlier unknown -> no is T00. Final earlier has E10 (missing citation), while final latest has E11 (older A cited for B). Correct values do not establish preserved provenance.
- **HA08:** reversed earlier unknown -> no with an unresolved A label is T12/S11, not successful correction and not a demonstrated known-fact delayed-revision failure.
- **HB08:** reversed earlier resolves correctly (T00), but latest unknown -> no is T15 because the initial latest was already incorrect. Historical correction and a wrong final recent answer can coexist.
- **HA05/HA09/HA10:** task qualification blocks semantic scoring before any model-failure category is assigned. Their format remains observable; no positive/negative labels are invented.

## What remains unproved

No code here proves internal forgetting, a visual perception deficit, arrival-recency bias, memory-capacity limits, shortcut use, model-size insufficiency or backend numerical error. Joint failure does not isolate perception from instruction/slot interpretation. The original evidence graph selected and qualified inputs; graph memory was never supplied to the model. No graph-memory benefit is measured.
