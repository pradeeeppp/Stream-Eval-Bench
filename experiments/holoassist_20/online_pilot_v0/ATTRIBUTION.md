The source recordings are from HoloAssist: Xin Wang et al., “HoloAssist: an Egocentric Human Interaction Dataset for Interactive AI Assistants in the Real World,” ICCV 2023. Project and official download information: https://holoassist.github.io/ . The project states a CDLA-Permissive 2.0 data license.

The local MP4s used to prepare this pilot were fetched from the pinned lmms-lab/EgoIT-99K HoloAssist mirror listed in `sources.json`. This branch provides a hash-verifying downloader for those 20 source MP4s and includes the exact selected frames in `../data/holoassist20-inputs.tar.gz`. Full source videos are not stored in Git or Git LFS. The mirror copies have not been byte-compared with the official HoloAssist archive. The dataset license and publisher notices continue to apply to the videos and extracted frames; the repository's code license does not replace them.

The publisher-specified CDLA-Permissive 2.0 license text accompanies this data in `../data/LICENSE-CDLA-Permissive-2.0.txt`; its official source is https://cdla.dev/permissive-2-0/ .
